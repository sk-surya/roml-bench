  • ROML Python (bulk) — ROML Python shaped/bulk path: Model.vars + add_linear_rows CSR (sparse_rows) or vectorized Model.add (bess_96); roml.sum/roml.dot objectives.
  • PuLP — PuLP: LpProblem.add_variable_dicts + lpSum helpers. Validation solves use the bundled CBC binary.
