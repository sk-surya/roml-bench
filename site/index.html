Model-construction benchmark v1

Correction to the v1 report

Correction to the v1 report: the 350x figure was naive O(n^2) expression chaining, not Python binding overhead, and the v1 BESS leaderboard mixed matrix ingestion (PyOptInterface) against high-level formulation (ROML). This report splits formulation from ingestion and renames the scalar arm accordingly.

How long does it take to build an equivalent linear model as the problem grows? Two separate questions are answered on separate panels: A. formulation (from B/T/prices or N: algebra, lowering, and ingestion) and B. matrix ingestion (from shared CSR/bounds/objective input). Primary metric: populate_ms, the elapsed construction-API time from the first variable insertion into an already-created empty model through objective installation. Imports, data generation, solves, serialization, and report generation are excluded.

Measured findings (paired points only)

  • sparse_rows formulation at paired size 1000000: fastest was ROML Python (bulk) (median 150 ms); ROML Python (naive chain) 7.44x vs ROML bulk; PuLP 13.46x vs ROML bulk; Pyomo 7.05x vs ROML bulk; PyOptInterface (scalar) 7.32x vs ROML bulk; JuMP (Julia) 5.31x vs ROML bulk; MathOpt (C++) 2.70x vs ROML bulk.
  • sparse_rows matrix ingestion at paired size 1000000: ROML Python (bulk) 150 ms, PyOptInterface (matrix) 1.62e+03 ms.
  • bess_96 formulation at paired size 300: fastest was ROML Python (bulk) (median 25.6 ms); ROML Python (naive chain) 6.42x vs ROML bulk; PuLP 18.58x vs ROML bulk; Pyomo 12.99x vs ROML bulk; PyOptInterface (scalar) 5.04x vs ROML bulk; JuMP (Julia) 6.28x vs ROML bulk; MathOpt (C++) 1.34x vs ROML bulk.
  • bess_96 matrix ingestion at paired size 300: ROML Python (bulk) 25.6 ms, ROML Python (CSR ingest) 25 ms, PyOptInterface (matrix) 205 ms.
  • ROML core named vs anonymous at sparse_rows 1000000: Named vs anonymous core: 1.03x. (median ratios, paired points only).
  • Censored points are shown as gaps, never extrapolated (1 stop events: error; see Data).
