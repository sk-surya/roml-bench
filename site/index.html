Model-construction benchmark v1

Correction to the v1 report

Correction to the v1 report: the 350x figure was naive O(n^2) expression chaining, not Python binding overhead, and the v1 BESS leaderboard mixed matrix ingestion (PyOptInterface) against high-level formulation (ROML). This report splits formulation from ingestion and renames the scalar arm accordingly.

How long does it take to build an equivalent linear model as the problem grows? Two separate questions are answered on separate panels: A. formulation (from B/T/prices or N: algebra, lowering, and ingestion) and B. matrix ingestion (from shared CSR/bounds/objective input). Primary metric: populate_ms, the elapsed construction-API time from the first variable insertion into an already-created empty model through objective installation. Imports, data generation, solves, serialization, and report generation are excluded.

Measured findings (paired points only)

  • sparse_rows formulation at paired size 100000: fastest was ROML Python (bulk) (median 23 ms); ROML Python (naive chain) 1488.50x vs ROML bulk; PuLP 7.37x vs ROML bulk; Pyomo 3.85x vs ROML bulk; PyOptInterface (scalar) 3.82x vs ROML bulk.
  • sparse_rows matrix ingestion at paired size 1000000: ROML Python (bulk) 412 ms, PyOptInterface (matrix) 1.59e+03 ms.
  • bess_96 formulation at paired size 300: fastest was ROML Python (bulk) (median 55.1 ms); ROML Python (naive chain) 84.82x vs ROML bulk; PuLP 8.51x vs ROML bulk; Pyomo 6.08x vs ROML bulk; PyOptInterface (scalar) 2.30x vs ROML bulk.
  • bess_96 matrix ingestion at paired size 300: ROML Python (bulk) 55.1 ms, ROML Python (CSR ingest) 36.1 ms, PyOptInterface (matrix) 212 ms.
  • ROML core named vs anonymous at sparse_rows 100000: Named vs anonymous core: 1.06x. (median ratios, paired points only).
  • Censored points are shown as gaps, never extrapolated (2 stop events: error, timeout; see Data).
